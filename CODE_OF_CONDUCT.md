# Code of Conduct

This project follows the Contributor Covenant.

Be respectful, inclusive, and constructive.

Harassment, discrimination, or abuse is not tolerated.

Report issues to the maintainers via GitHub issues.

Violations will be reviewed and addressed promptly.

See https://www.contributor-covenant.org/version/2/1/code_of_conduct/

Enforcement is at the maintainers' discretion.

Thank you for helping keep LestraOS welcoming.
